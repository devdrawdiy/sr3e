## Install

You'll need a licensed copy of Foundry Virtual Tabletop. In Foundry's system installation dialog, paste this manifest URL:

```
https://github.com/devdrawdiy/sr3e/releases/latest/download/system.json
```

Create a new World using the sr3e system, launch it, and you're in.

## Your first character

Open the **Actors** sidebar tab and create a new Actor of type **Character**. sr3e intercepts the normal creation flow and opens its own character creation dialog instead of an empty sheet — pick a metatype, assign priorities, and spend your starting points there. When you're done, your character sheet opens fully populated and ready to play.

## Your first roll

Character sheets carry a roll composer in the header — use it to build and send a dice-pool roll (attribute, skill, or a weapon's attack) straight to chat. Combat and contested actions (melee, firearms, spellcasting, resistance tests) walk both sides through the roll automatically once the first roll is made.
